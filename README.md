# ОРБИТА — интерактивный атлас планет

**Итоговая практическая работа по HTML, CSS и JavaScript.**

«ОРБИТА» — самостоятельный адаптивный сайт об **8 планетах Солнечной системы**. Все страницы, стили, иллюстрации и JavaScript-код включены в проект. Сборка и установка пакетов не нужны.

>
> Репозиторий GitHub: **https://github.com/ga223-tech/site**.
> GitHub Pages (после включения): **https://ga223-tech.github.io/site/**.

## Возможности

- Семантическая главная страница с hero-блоком, закреплённой шапкой, 5 пунктами навигации, мобильным бургер-меню и подвалом.
- Слайдер на JavaScript: 3 слайда, стрелки, точки, автопереключение каждые 5 секунд, пауза при наведении и фокусе.
- 8 карточек планет, генерируемых из массива JavaScript через `map()` и `join()`.
- Категории, поиск, hover-эффекты, адаптивная сетка **4 → 2 → 1** и модальное окно «Подробнее».
- Регистрация и вход с проверкой имени, email, длины пароля, совпадения паролей, согласия и уникальности email.
- Сохранение пользователей и сеанса в `localStorage`; пароли не хранятся в открытом виде (PBKDF2 через Web Crypto API).
- Защищённый на уровне учебного интерфейса личный кабинет: имя, email, дата регистрации, избранное и выход.
- Избранное сохраняется отдельно для каждого пользователя в `localStorage`.
- Раздел «О проекте», FAQ, контакты (демонстрационные) и ссылки на полезные ресурсы.
- Локальные оригинальные SVG-иллюстрации без загрузки изображений со сторонних серверов.

## Как запустить локально

**Рекомендуется локальный HTTP-сервер**. Из папки проекта:

```bash
python -m http.server 5500
```

На некоторых системах команда называется `python3`. Откройте **http://localhost:5500** в браузере. Вместо Python можно использовать расширение **Live Server** в VS Code.

Открытие `index.html` двойным кликом иногда работает, но режим `file://` может ограничивать `localStorage` или Web Crypto в отдельных браузерах. Для проверки регистрации всегда используйте localhost или HTTPS.

Никаких внешних библиотек, сборщиков, Node.js и npm не требуется. Интернет желателен только для загрузки Google Fonts; без него используются системные шрифты.

## Как проверить

1. Перейдите на главную, переключите слайдер стрелками и точками.
2. В каталоге попробуйте категории и поиск по названию «Марс». Откройте подробную карточку.
3. Откройте `cabinet.html` до входа — увидите отказ.
4. Перейдите на `auth.html#register` и зарегистрируйте **выдуманного** пользователя с учебным паролем длиной от 6 символов.
5. После регистрации откроется кабинет с именем, email и датой.
6. Вернитесь на главную, добавьте планету в избранное сердечком. Проверьте её в кабинете.
7. Обновите кабинет: избранное и данные не должны исчезнуть.
8. Нажмите «Выйти», попробуйте снова открыть кабинет, затем войдите с созданными данными.
9. Откройте DevTools → адаптивное устройство или уменьшите ширину окна: проверьте бургер и сетку 4→2→1.

Подробный сценарий, подготовка к защите и публикация на GitHub Pages — в **[GUIDE.md](GUIDE.md)**.

## Учебная авторизация и данные

Это **не настоящий сервис аутентификации**. Список пользователей и текущий сеанс лежат в `localStorage`, который контролируется самим пользователем и доступен JavaScript. PBKDF2 уменьшает риск хранения паролей открытым текстом, но **не превращает браузерную имитацию в безопасную серверную авторизацию**. Не вводите здесь свои настоящие пароли или личные данные. Очистка данных браузера удалит созданные аккаунты и избранное.

## Проверки

Статическая проверка JavaScript: `node --check js/data.js`, `node --check js/auth.js`, `node --check js/main.js`.

Дополнительные автоматические проверки в `tests/test_site.py` используют Python и Playwright **только для тестирования**, не для работы сайта. В ограниченной среде они выполняют страницы в памяти, эмулируя localStorage и Web Crypto, поэтому не заменяют ручную проверку настоящего сайта на `localhost`. Результат проверки при подготовке: **19 / 19**, ошибок в JS не было. Скриншоты получены на этом in-memory рендеринге; вид может слегка отличаться при загрузке Google Fonts в обычном браузере.
